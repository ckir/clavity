Release Changelog

Comprehensive release history across all Clavity ecosystem members.

Monorepo Releases

Clavity ships coordinated umbrella releases tagged clavity-v<N> on GitHub. Each release bundles compiled binaries, SHA-256 checksums, and marketplace plugins.

  • Browse All GitHub Releases — Download release binaries and checksum files.

Per-Member Changelogs

Each member maintains its own strict conventional changelog in the repository:

  • clavity-dotnet CHANGELOG — Language Server updates and MCP tooling.
  • clavity-classic CHANGELOG — Standalone Rust bridge updates.
  • agy-autotrain CHANGELOG — Knowledge capture and probe improvements.
  • commonmemory CHANGELOG — Cross-agent notebook enhancements.
  • review-relay CHANGELOG — Web model review and browser extension updates.
