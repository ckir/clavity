# Clavity Campaign Copy Staging

Central repository for draft launch copy, channel posts, and email templates.

> [!IMPORTANT]
> **Draft Materials:** All documents in this directory represent staged pre-launch copy. None of these materials are published automatically or distributed without explicit human approval.

## Copywriting Invariants

1. **Factual Grounding:** Only cite capabilities verified in code (see [`docs/marketing/positioning.md`](../../docs/marketing/positioning.md)).
2. **No AI Clichés:** Never use forbidden buzzwords ("seamless", "game changer", "blazingly fast", "superpower", or excessive exclamation marks).
3. **Transparent Limitations:** Always disclose prerequisites (Claude Code, Google Antigravity, and `superpowers` required).
4. **License Clarity:** Clarify that public evaluation is free under the PolyForm Noncommercial 1.0.0 license.
