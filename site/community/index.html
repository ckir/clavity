GitHub Discussions

Our primary community hub is GitHub Discussions. We organize discussions into three focused categories:

Show and Tell

Share pairing sessions, capstone review wins, and before/after diffs from your real-world projects.

Join Show & Tell

Q&A & Troubleshooting

Get assistance with Antigravity quota configuration, psmux setup, or Language Server troubleshooting.

Ask a Question

Feature Ideas

Propose new review seats, alternative model harnesses, or shared memory protocols.

Issue Reporting & Bug Tracking

Found a defect in clavity-ls or a broken assumption in Antigravity driving? We provide structured issue templates in GitHub:

  • Submit a Bug Report — Include OS, terminal environment, and session transcript excerpts.
  • Submit a Feature Request — Suggest actionable product improvements.
  • Submit Beta Feedback — Share experience from public beta evaluation.

Contributing Code

Clavity welcomes technical contributions from the community. Review our CONTRIBUTING.md guide for local build instructions, running tests with just test, and pre-push quality gates.
