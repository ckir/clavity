commonmemory

Shared cross-agent memory convention and notebook built on the agentmemory signal bus.

Problem Solved

In standard multi-agent workflows, each agent maintains its own ephemeral context window. When Claude discovers a subtle dependency bug or project convention, that insight is lost when a subagent exits, and remains invisible to the Antigravity peer unless manually repeated in prompts.

commonmemory establishes a standardized tagging convention and persistent memory notebook that both Claude Code and Antigravity can write to and query dynamically.

Main Capabilities

  • Structured Fact Tagging: Categorizes project learnings under standard tags (decisions, gotchas, bugfix, architecture).
  • Cross-Session Persistence: Keeps critical repository knowledge available across separate terminal invocations.
  • Proactive Context Injection: Teaches agents when to consult the shared memory store before planning new features.
  • Zero Cloud Relays: Operates locally via the lightweight @agentmemory/agentmemory package.

Installation & Setup

1. Ensure the @agentmemory/agentmemory dependency is installed:

  • npm install -g @agentmemory/agentmemory

    • 2. Install the Clavity plugin:

  • claude plugin install commonmemory@clavity

    • Requirements & Prerequisites

    RequirementSpecification
    Runtime DependencyNode.js / npm (for @agentmemory/agentmemory)
    Host PluginClavity Bridge (clavity-dotnet or clavity-classic)
    Supported AgentsClaude Code and Google Antigravity

    Known Limitations

    • Requires Node.js runtime on PATH to support the agentmemory CLI bus.
    • Memory entries are scoped to the active workspace repository.
