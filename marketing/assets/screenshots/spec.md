## Capture Guidelines

- **Terminal Styling:** Dark theme background (`#020713`), monospace font (Fira Code or JetBrains Mono, size 14pt).
- **Window Framing:** Subtle rounded window border with standard macOS or Linux titlebar dots.
- **Privacy:** Sanitize all local usernames, private directory paths, and git commit hashes prior to publication.
