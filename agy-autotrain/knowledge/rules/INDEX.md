# agy-driving knowledge store

Tier 2 of the knowledge tiering: **unbounded, never injected, version-controlled**. The injected
GROWTH region is a bounded *selected projection* of this store, not the store itself.

Seeded 2026-08-27 by splitting the 18 rules of the compiled runtime GROWTH into one file each. Before
that split the entire earned corpus - 18 compiled rules and 165 raw observations - existed ONLY
at runtime paths on one machine, with nothing but the filesystem preserving it.

**A rule absent from GROWTH is not gone; it is not currently projected.** Retire a rule by editing
its file, never by deleting it: git history is the preservation tier.
