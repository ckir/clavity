Clavity Public Beta Program

Evaluate dual-agent pairing in your own codebase. No account or registration is required to start.

Zero Gatekeeping: You can install and use Clavity right now from your terminal without providing an email address or joining a waitlist. Registration below is entirely optional for developers seeking release announcements or commercial pilot participation.

Quickstart Evaluation

Install the bridge directly in Claude Code:

  • claude plugin marketplace add ckir/clavity
  • claude plugin install clavity@clavity

    • Launch a pairing session by running /brainstorm in any repository with superpowers installed.
