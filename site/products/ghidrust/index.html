Project Migration Notice

ghidrust

Headless Ghidra reverse-engineering over MCP — migrated to standalone repository.

Status Update (September 14, 2026): ghidrust was fully retired from the Clavity monorepo to maintain Clavity's exclusive focus on multi-agent collaboration. Its reverse-engineering capabilities have been superseded by the standalone plugin re-ghidra-mcp-cc.

Original Capabilities

ghidrust was a single-binary pure-Rust MCP server exposing 19 reverse-engineering tools (decompiler, disassembly navigation, symbol renames, cross-references) connected to a persistent headless Ghidra JVM process.

Where to Find It Today

Developers seeking headless Ghidra reverse-engineering inside Claude Code should install the dedicated standalone tool:

  • claude plugin install re-ghidra-mcp-cc@aiplugins

    • For migration history and release notes, consult the migration guide in the repository.
