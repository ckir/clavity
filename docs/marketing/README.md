# Clavity Marketing & GTM Documentation

Overview and index for Clavity's Go-to-Market (GTM), positioning, website specification, and commercial validation documentation.

## Purpose

This directory contains the operational and strategic scaffolding for transitioning Clavity from an open developer tool into a recognized developer product with an active public beta community and an evaluated commercial tier.

## Ownership & Maintenance

- **Source of Truth:** Repository code and architecture take precedence over forward-looking marketing projections.
- **Hypothesis Separation:** Market hypotheses (such as commercial tier definitions) must be explicitly identified as hypotheses.
- **Review Frequency:** Update upon every minor version bump or completion of milestone gates.
