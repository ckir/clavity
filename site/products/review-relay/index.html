review-relay

Assisted review rounds with web-based AI models (ChatGPT, Gemini, Meta AI, Claude Web) via browser integration.

Problem Solved

Many state-of-the-art reasoning models are accessible via web chat interfaces before they become available via local API keys, or developers may have existing web subscriptions they wish to leverage for code review without incurring additional API costs.

review-relay enables Claude Code to prepare structured review prompts for external web models. You paste them into the web interface, save the output using the bundled browser extension, and Claude automatically ingests and verifies the findings against the real code.

Main Capabilities

  • Structured Prompt Preparation: Claude formats targeted review rounds with file:line context and explicit verification instructions.
  • Browser Extension Integration: Captures model responses using the bundled AiSaveDev / AiSave browser extension.
  • Ground-Truth Verification: Claude cross-checks web model claims against the actual local repository before folding any suggestions.
  • Provider Agnostic: Compatible with ChatGPT (OpenAI), Gemini Advanced (Google), Claude Web (Anthropic), Meta AI, or DeepSeek.

Installation & Setup

Install via the Claude Code marketplace:

  • claude plugin install review-relay@clavity

    • Load the unpacked extension in your browser from review-relay/extension/.

    Requirements & Prerequisites

    RequirementSpecification
    BrowserChromium-based browser (Chrome, Brave, Edge) or Firefox
    Host ToolClaude Code CLI
    Web AccountsAny AI chat service (ChatGPT, Gemini, Meta AI, etc.)

    Known Limitations

    • Requires manual copy-paste interaction across browser windows.
    • Responses depend on web service availability and third-party terms of service.
