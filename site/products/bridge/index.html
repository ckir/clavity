Clavity Bridge

High-performance Language Server and MCP bridge connecting Claude Code and Google Antigravity.

Problem Solved

Single-agent coding tools operate in an isolated confirmation loop: the same model that generates an implementation also validates it, often overlooking subtle edge cases, invalid test assertions, or architectural drift. Running two independent AI tools manually requires tedious copy-pasting across terminal tabs.

Clavity Bridge automates direct peer communication between Claude Code (driver) and Antigravity (peer) within the same repository workspace.

Implementations & Architecture

The bridge provides two mutually exclusive implementations:

clavity-dotnet (Primary)

Cross-Platform (.NET 10)

A modern Language Server (clavity-ls) that exposes Antigravity to Claude Code as an in-process MCP server over stdio. Automatically downloads verified pre-built binaries on first run.

Explore source on GitHub

clavity-classic (Failover)

Windows Only (Rust)

The original bridge implementation written in pure Rust. Uses a psmux doorbell and the agentmemory signal bus to communicate with a live Antigravity peer.

Explore source on GitHub

Main Capabilities

  • Adversarial Panel Review: Convenes multi-seat expert review panels (Architecture, Security, Performance) via Antigravity before implementation begins.
  • Pre-Completion Capstone Review: Multi-round, citation-verified code audits (agy-capstone) that must pass before a task is marked complete.
  • Test Audit Hardening: Exhaustive test suite audits (agy-test-audit) verifying that unit tests actually catch regressions.
  • Automatic Defect Capture: Collects repository bugs encountered during agent execution into a ranked backlog via start the triage.
  • Zero Network Relays: All communications execute locally over stdio and process pipes.

Installation & Setup

Install the marketplace plugin directly in your terminal:

  • claude plugin marketplace add ckir/clavity
  • claude plugin install clavity@clavity

    • The plugin automatically fetches the matching clavity-ls binary for Windows x64, Linux x64, macOS Apple Silicon, or macOS Intel from GitHub Releases.

    Known Limitations

    • Requires an active Google Antigravity quota or local fallback mode.
    • Peer review rounds consume API tokens across both model providers.
    • clavity-classic is limited to Windows systems.
